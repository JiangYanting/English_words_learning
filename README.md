# English_words_learning
英语单词学习小程序（HTML网页文件，离线可用）

# 小程序特点
（1）提供小练习、错题本、收藏夹、词库管理4个基本模块。

（2）各模块均能展示来自《柯林斯高阶英汉词典》的英英释义，将单词放在句子里面理解，更好地掌握其用法。

（3）每个单词提供了该单词在coca（美国当代英语语料库）里的词频排序信息。例如the最常见排第1，it排第10，tree排第596。

（4）可以自己导入、导出词库（json格式）
